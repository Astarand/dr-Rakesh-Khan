## 🧠 About The Project

This is a professional single-page portfolio website developed for **Dr. Rasheed Khan**, designed to present medical expertise, services, and professional background in a clean and structured format.

The website focuses on delivering a smooth user experience, building patient trust, and ensuring easy access to essential information.

---

## 🎯 Objectives

* Showcase medical expertise and experience
* Provide clear information about services
* Build trust with patients
* Maintain a clean and professional online presence
